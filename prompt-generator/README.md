# Prompt Generator

This project is a simple offline webpage for generating prompts. It consists of an HTML file, a CSS file for styling, and a JavaScript file for functionality.

## Project Structure

```
prompt-generator
├── css
│   └── styles.css
├── js
│   └── app.js
├── index.html
└── README.md
```

## Files Description

- **index.html**: The main HTML document for the prompt generator webpage. It includes the structure of the webpage and links to the CSS and JavaScript files.

- **css/styles.css**: Contains the styles for the webpage, defining the layout, colors, fonts, and other visual aspects.

- **js/app.js**: Contains the JavaScript code that handles user interactions, generates prompts based on user input, and updates the webpage dynamically.

## Usage

1. Open `index.html` in a web browser to access the prompt generator.
2. Enter your desired inputs in the provided fields.
3. Click the generate button to create a prompt based on your inputs.
4. The generated prompt will be displayed on the webpage.

## Setup

No additional setup is required. Simply download the project files and open `index.html` in your preferred web browser to start using the prompt generator.
