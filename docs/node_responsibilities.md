It was generated by reviewing `noxprompter.nodes.NODE_CLASSES` and the
runtime inspection helper at `tools/inspect_node_inputs.py`.

## Highlights

* The shared inspection script outputs the raw required/optional input keys for
  every node. Run it with:

```powershell
C:/Users/James/Documents/GitHub/ComfyNoxPrompter/.venv/Scripts/python.exe tools/inspect_node_inputs.py
```

* True **camera option sets** (enumerated selections backed by
  `CAMERA_*` constants) now reside solely in dedicated camera nodes:
  - `NoxPromptCameraMaster`
  - `NoxPromptCameraLanguage`
  - `NoxPromptAdvancedCamera`
  - `NoxPromptCamz` (`camera_style` preset family)

* Several non-camera nodes also expose *text* fields for camera notes; these can
  stay once preset-driven overlaps are resolved.

* Remaining shared preset libraries:
  - Character archetype/profession tables shared across `BlueprintGenerator` and `CharacterCreator`.
  - Motion/emotion tables used in both `Builder` and action/pipeline nodes.

This document will be updated as overlaps are resolved.
